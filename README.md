Heart Disease Prediction - Real-World Data Project

Domain: Health (Patient Records)
Due Date: 29 May 2026

DATASET
- 303 patient records
- 13 features: age, sex, chest pain, blood pressure, cholesterol, etc.
- Target: Heart disease present or not

EDA PERFORMED
- Age distribution by disease
- Gender vs disease comparison
- Cholesterol box plot
- Max heart rate vs age scatter plot
- Chest pain type analysis
- Feature correlation heatmap

ML MODELS
- Logistic Regression : 93.44% accuracy
- Random Forest       : 93.44% accuracy

TOP RISK FACTORS FOUND
- ST depression (oldpeak)
- Max heart rate (thalach)
- Age, Cholesterol, Exercise-induced angina

TOOLS USED
- Python, pandas, numpy
- matplotlib, seaborn
- scikit-learn
